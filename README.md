# 五子棋游戏 (Gomoku Game)

A fully functional web-based Gomoku (Five in a Row) game implemented with HTML, CSS, and JavaScript.

### How to Play

1. Open `gomoku.html` in any modern web browser
2. Black player goes first - click on any intersection on the board to place a stone
3. Players alternate turns between black and white
4. The first player to get 5 stones in a row (horizontally, vertically, or diagonally) wins
5. Click the "重新开始" (Reset) button to start a new game

### Features

- 15x15 traditional game board
- Beautiful UI with gradient backgrounds and 3D stone effects
- Real-time turn indication
- Win detection in all directions
- Responsive design for different screen sizes
- Chinese language interface

### Files

- `gomoku.html` - Main game interface
- `gomoku.css` - Styling and visual design
- `gomoku.js` - Game logic and mechanics
